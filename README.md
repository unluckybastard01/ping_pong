# Прототип игры «Пинг-понг» 🏓

Классическая аркадная игра для двух игроков, написанная на Python с использованием библиотеки **Pygame**. Проект реализован с применением объектно-ориентированного программирования (ООП).

В этой версии стандартные прямоугольники заменены на кастомные спрайты (изображения игроков и мяча), добавлен красивый фон, фоновая музыка и автоматический подсчет очков.

## 🎮 Особенности

* Локальный мультиплеер (два игрока за одной клавиатурой).
* Кастомная графика: уникальные модели ракеток (вид сверху), мячик и космический/стилизованный фон.
* Музыкальное сопровождение во время игры.
* Счетчик очков в верхней части экрана.
* Простая и понятная архитектура кода на базе классов (спрайтов).

## 🕹️ Управление

* **Игрок 1 (Слева):**
* `W` — движение вверх
* `S` — движение вниз


* **Игрок 2 (Справа):**
* `Стрелка Вверх` (⬆️) — движение вверх
* `Стрелка Вниз` (⬇️) — движение вниз



## 🛠️ Установка и запуск

1. Убедитесь, что у вас установлен **Python** (версии 3.6 или выше).
2. Установите библиотеку Pygame, выполнив в терминале/командной строке:
```bash
pip install pygame

```


3. Скачайте этот репозиторий (все файлы должны находиться в одной папке).
4. Запустите основной файл игры:
```bash
python main.py

```



## 📁 Структура файлов (Ассеты)

Для корректной работы игры убедитесь, что в папке со скриптом находятся следующие медиафайлы:

* `main.py` — основной код игры.
* `1.png` — изображение мяча.
* `istockphoto-472296663-170667a.jpg` — фоновое изображение.
* `top-view-man1.png` — спрайт левого игрока.
